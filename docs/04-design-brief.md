# 04 — Design Brief

- **Direction:** Linear UI (crisp contrast, calm data density, `tabular-nums` currency alignment) + Notion (scannable project workspace) + Apple motion restraint.
- **Theme:** Semantic light & dark OKLCH tokens via `globals.css` (zero manual `dark:` color overrides in components; flash-free theme toggle).
- **Typography:** Inter (UI) + JetBrains Mono (ARNs, CLI commands, Terraform snippets, and tabular dollar amounts).
- **Motion:** `scale(0.97)` tactile active press on interactive controls, smooth GPU-composited transitions, no decorative continuous motion.
