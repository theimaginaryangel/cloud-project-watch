# TagWatch Ubiquitous Language Glossary

All TypeScript types, Zod schemas, database tables, API payloads, and UI copy must use these exact domain terms.

| Term | Definition |
| :--- | :--- |
| **AwsConnection** | A configured source of AWS resource snapshots (`demo`, `iam_keys`, or `env_default`), with target regions and optional 24h Cost Explorer toggle. |
| **ScanRun** | A single point-in-time discovery run (`running` / `completed` / `failed`) guarded by a deterministic `idempotencyKey` and a per-connection active-run lock. |
| **ResourceSnapshot** | One discovered billable AWS resource (`ec2`, `ebs`, `eip`, `nat_gateway`, `rds`, `secrets_manager`, `elb`) with exact integer microcent hourly cost and monthly cent cost. |
| **ProjectBucket** | A logical project grouping (`cloudpress`, `kaluna`, `bankguard`, or `__orphaned__`) aggregating its `ResourceSnapshot`s, monthly burn, and surgical savings. |
| **ProjectRule** | A user-configured mapping rule (`arn_override`, `tag_key`, `name_prefix`) that maps resources into a `ProjectBucket`. |
| **RuleFinding** | A zero-cost, deterministic optimization alert computed directly from a `ResourceSnapshot` (e.g., `UNATTACHED_EIP`, `RDS_7DAY_AUTORESTART`, `SECRETS_TO_SSM`). |
| **SurgicalPlan** | An on-demand, structured JSON cost-cutting playbook generated by Gemini or Groq (cached by `snapshotHash`) that cuts cost while keeping live apps running. |
| **CostExplorerSync** | An optional, DB-locked cached snapshot from `ce:GetCostAndUsage` strictly limited to 1 call per 24 hours per connection. |
